# 全站 26 頁核對與修正

基準：FM24_World_Master_v6.4.0_award_delta_2034_35.final。這輪逐一開啟 26 個主頁，對照建置程式、來源表及資料採用規則；修改後再逐頁回查，另實際操作受影響的篩選、導覽與匯入預覽。

## 結論

網站已有足夠的互動內容，主要問題是不同頁面的資料口徑未一致：球員名錄補齊後，榮譽殿堂與巴薩個人頁仍使用不同子集；缺值與沒有紀錄也有被當作零或一筆獎項的情況。本輪先統一這些閱讀結果，再補榮譽對決，沒有改寫 Excel 主檔。

榮譽比較不產生綜合分數，不把入選序號當名次，不把多份證據變成多次得獎。曆年與球季分開篩選，個人獎項不套用每場效率；逐季歸屬表沒有世俱盃欄位時顯示未知。0 表示已收錄且能關聯的紀錄為零，不能解讀成已證明此人生涯從未得獎。

亞馬爾三個入口一致：54 筆紀錄，21 次得獎、16 次入選、17 次其他名次。37 次得獎／入選均可對應主檔摘要，摘要本身不再加一次。全體受控球員合計 1,151 筆個人紀錄；另有 471 筆來源列尚無唯一受控身分，保留於全站查詢與證據中，不猜測塞給球員。教練獎保留在全站目錄，排除於球員個人榮譽。

## 驗收與邊界

- Excel → SQLite：唯讀比對全部 122 張表、27,124 列、339,738 個資料儲存格與原始列號。依 ETL 宣告的空白／日期／文字正規化後一致，工作簿 SHA256 未改變。這項證明資料鏡射一致，不代表每個儲存格都在主頁展示。
- HTML 內嵌資料與 JSON 匯出逐項相等（排除 JSON 專用 `_readme`）。
- Python：220 passed；JavaScript：20 passed。新增測試涵蓋榮譽分類、不同時間範圍、未知團隊冠軍、CSV 引號與末尾空值、目錄不漏 CAF 來源、未解析同名不可誤合併、國家隊空值、編年史排序及退役分段完整性。
- JavaScript 整份產物語法檢查通過。修改後回查全部 26 個主頁；修復預覽中發現的錯誤後，重跑相關操作與全頁回查沒有新增 JavaScript 錯誤。
- 這是全主頁與受影響互動的查核，不是所有瀏覽器、所有篩選組合或每個來源事實的人工逐條真偽認證。沒有遊戲截圖的新證據，不自行補缺值或更改主檔矛盾。

## 下一步最有價值的改善

1. **全世界球員榮譽專用比較。** 現有球員對決使用 30 名巴薩生涯檔案，保證統計範圍一致。可另開全名錄的榮譽比較，讓姆巴佩、哈蘭德等也能比；不能直接把世界聯賽數據混進巴薩各項賽事生涯。
2. **得獎時間軸與榮譽卡。** 將已關聯的榮譽依年／季視覺化，海報列出三類次數與收錄範圍。可以使用現有去重明細，不必再做第三套計數。
3. **主檔待核對清單按影響排序。** 先處理影響明星球員榮譽、重複俱樂部及同屆分組的問題。已有候選不代表身分已確認；確認結果需經受控資料採用流程，不能以字串相似度自動消除待辦。
