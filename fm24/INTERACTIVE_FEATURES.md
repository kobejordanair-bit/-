## 資料紀律

- 新增 `experience.py` 直接讀主表數值，缺值、無效值與非有限數保留 null。生涯使用 Barcelona_Player_Career，不把零散逐季列重新加總成生涯。
- 逐季只採用巴薩 C-0030 且 Statistical_Adoption_Status 明示 ADOPTED 的資料；同球季若有多筆觀測，比較頁不任選、不相加。
- 每次出場效率包含替補出場，沒有分鐘資料，因此不寫成每 90 分鐘。評分不除以出場次數。缺季折線中斷，缺值不視為零。
- 屬性圖僅比較同類型快照、共同提供的欄位；保留雙方快照日期與來源。分類平均不是 CA、PA 或位置適配分數。
- 冠軍確認沿用正式季末或 Domestic_Leagues，來源未確認的榜首不算冠軍；不同聯賽不以總積分硬排實力。
- 德比保留原始比分。修正尾端「加／点」註記的辨識，46 場比分均可解析；點球和局不推測勝者。未註日期的紀錄置末，不能延長連續不敗紀錄。
- 夢幻 XI 是使用者自選跨年代陣容，不代表目前註冊球員，也不修改任何遊戲內位置或能力。更換陣型保留格位索引，需自行確認新位置。
- PNG／SVG 由瀏覽器在本機產生；海報保留來源表、統計範圍、版本及缺值說明。沒有新增追蹤、外部圖片、AI 呼叫或伺服器寫入。既有 Google Fonts 樣式載入保持原設計，離線時用系統字型。

## 建置與維護

`experience.js`、`experience.css` 是來源模組；`build_site.py` 會把它們與 JSON 全部嵌入單一 `archive.html`。部署時不需要另外載入模組，也不依賴第三方 JavaScript 套件。

```sh
python build_site.py --standalone -o archive.html
python build_site.py --json dist/fm24-data.json
python -m pytest test_resolver.py test_evidence.py test_history.py test_integrity.py test_experience.py -q
node --test test_experience.js
```

實跑 **206 項 Python 測試通過（42.91 秒，0 skipped）**，**14 項 Node 測試通過**。新增測試覆蓋來源逐欄數值、null、採用範圍、逐季歧義、效率分母、點球與尾端註記、未註日期連續場次、XML 逸出及夢幻陣容防重複／清空／網址驗證。

瀏覽器驗證包含比較條件重新整理還原、缺季顯示、屬性來源、年份切換、球員快速搜尋、陣容交換及本機保存／載入、PNG 產生、三種海報主角與配色、390 px 手機版面及深色主題。PNG 或 SVG 若未被內建瀏覽器自動接收，可使用產生後的「開啟圖片另存」連結；連結為本機 Blob，有效五分鐘。

全部 26 個頁面逐一開啟，無瀏覽器 JavaScript 錯誤；德比播放確認自動推進到篩選範圍最後一場並停止。測試環境的內建瀏覽器安全政策禁止另開 Blob 網址，因此「另開圖片」與實際下載落地未能完成端到端驗證；沒有繞過限制。已驗證海報 SVG 預覽及 Canvas 產生 PNG 成功。
