# 球員比較整合與擴充

原「球員對決」只選巴薩球員，與「世界榮譽對決」重複選人、分享及獎項邏輯。本輪合併為單一 `#/duel`「球員比較」入口，涵蓋主檔全部 332 個受控身分。全站由 29 個入口整理為 28 個，既有功能保留。

## 五個分頁

| 分頁 | 功能與口徑 |
|---|---|
| 比較總覽 | 同一對球員的 Profile 日期、所選表現範圍、全期間榮譽分項、資料涵蓋與來源 |
| 表現與生涯 | 全球聯賽紀錄／巴薩各項賽事切換，累計／逐季，總量／每場效率，進球趨勢、缺值完整度及來源列 |
| 個人榮譽 | 得獎／入選／其他名次分開；曆年、球季、期間、獎項、結果交叉篩選；逐期對照與時間軸／榮譽卡 |
| 屬性快照 | 兩人各自指定來源日期，預設最新唯一快照；共同分類雷達、逐欄值與差異、完整列號 |
| 巴薩團隊榮譽 | 累計或指定球季的在隊團隊成就；非巴薩球員顯示未知，不推定零冠軍 |

選人、交換、姓名／別名搜尋與分享連結共用。交換球員時，所選屬性快照跟著本人交換。榮譽篩選和表現期間是兩套明示的範圍，避免曆年與跨年球季互相污染。

總覽保留榮譽卡及巴薩球員生涯卡的直接入口。

## 新接入資料與計算規則

- `comparison.players` 保存世界名錄的聯賽逐季來源、Profile 與屬性快照。
- 聯賽只採 `Player_League_Career.Statistical_Adoption_Status = ADOPTED`：532 段、39 個球員身分。兩列未採用觀測不進比較。
- 38 個球員身分有主檔屬性快照。數值逐格取來源；空值、非數字、超出 1–20 的值不作有效屬性。
- 已收錄聯賽累計不是完整生涯宣稱；同季不同俱樂部可相加，同季同俱樂部重複或 Fact ID 重複則停止加總。
- 任一段缺少某欄，該欄合計保持未知；原始零保留。提供「已填／在檔段數」查明缺口。
- 多段評分不做簡單平均；每次出場效率包含替補，不等於每 90 分鐘。
- 巴薩生涯數字直接採主表，逐季只採正式觀測；不從零散逐季列重算巴薩生涯。
- 趨勢補出兩側都缺少的中間球季並以 null 中斷折線，不將缺季畫成零或連續軌跡。
- 切換到缺少所選球季的球員，仍保留已知球季條件，不靜默重設為生涯累計。
- 同日有多份屬性快照時不猜採用哪一份，可明選來源；門將和外場不繪共同雷達、不計跨類型差值。
- 最新 Profile 欄位缺漏維持未知，不用舊 Profile 無標示補回。

## 舊連結相容

- `#/honourlab?hA=...&hB=...&hcClock=...` 轉入 `#/duel?compareTab=honours`，保留人物與榮譽條件。
- 舊 `#/duel?duelScope=...` 預設維持巴薩口徑，避免舊分享內容意義改變。
- 球員名錄、互動中心及時間軸改用同一比較入口。舊重複頁面的 renderer 已移除。

## 驗證

- Python 233 項與 Node 42 項通過，共 275 項。
- 已操作五個分頁、非巴薩身分、缺表現／缺屬性、曆年榮譽、日期選擇與交換、舊榮譽網址轉接、時間軸往返及缺季條件保留。
- 合併後 28 個功能入口逐頁開啟，未出現 JavaScript 錯誤或錯誤物件文字；總覽完成視覺檢查。
- 來源仍為 122 表、27,124 列、339,738 個資料格，Excel／SQLite 逐格一致；HTML 與 JSON 內容一致。
- 個人榮譽 1,151 筆、未綁定 471 筆維持原值。整合比較功能未採用候選身分、未修改工作簿。

較早的 `HONOUR_FEATURES.md` 與 `ALL_PAGES_REVIEW.md` 是當時版本驗收紀錄；目前入口數與比較功能以本文為準。
