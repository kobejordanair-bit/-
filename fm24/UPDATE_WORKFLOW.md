# Excel ⇄ HTML 更新與備份

網站左側選 **更新與備份**。工作簿仍是正式主檔；網站負責完整重建、核對與展示。

## 平常更新：選檔、預覽、套用

1. 在 Excel 更新 World Master，重新計算並儲存為 `.xlsx`。
2. 到網站選擇這份 Excel。也能選新版完整 HTML 或 `FM24_EXCHANGE_V1` 交換 JSON。
3. 檢查工作表增減、資料列變動、欄位增減、個人榮譽數與最新聯賽賽季。有移除／替換列時，確認勾選後才可套用。
4. 按「套用此版本」。更新原子寫入 IndexedDB，重新整理後仍保留；套用前版本會一併保存。相同檔案不重複匯入。
5. 重要版本下載完整 HTML 或交換備份。瀏覽器只保留最近五版；清除網站資料會清除本機歷史。

整份 Excel 是**版本替換**，不會把每份檔案相加。過期檔、工作表刪除與修正列必須查看預覽；程式無法從檔名可靠判斷遊戲世界線是否較新。

## HTML 回到 Excel

新版 HTML 內含原始 Excel，按「取回原始 Excel」得到相同 SHA-256、相同位元組的工作簿，保留所有分頁、未展示欄位、公式、格式與其他原始內容。網站不重新拼造工作簿。

新版 HTML 匯回網站時，只解析 JSON 並取出 Excel，使用**目前網站的程式**重建；不執行上傳 HTML 的 JavaScript，也不信任上傳檔自帶的引擎。

舊 HTML／舊純資料 JSON 沒有原始 Excel，只能當網站快照使用。畫面會明示無法逐表比較與取回完整 Excel；缺少目前必要資料區塊的老版本會要求改選 Excel。缺資料不補零、不臆測，也不把展示資料冒充完整主檔。

## 本機套用與公開網站

本機套用只影響目前瀏覽器，不會改寫電腦上的 Excel，也不會自動更動公開 GitHub 網站。

確認版本後展開「更新公開網站」：下載發布版 `archive.html` → 開啟 GitHub 上傳頁 → 上傳至 `main/fm24/archive.html` 同名替換並提交。Pages 完成後就是新版公開網站。分享個別存檔則下載一般「完整 HTML」即可。

公開站換了基準工作簿或程式時，舊本機版本不會靜默蓋掉新基準。歷史版本保留，必要時先用新程式重建再套用。多分頁同時切換版本時，後提交的過期預覽會拒絕覆蓋，要求重新整理核對。

## 待審資料、身分決定與筆記

整份工作簿更新不會刪除瀏覽器中的待審觀測或筆記。為避免分享 HTML 意外附帶個人整理內容，它們使用獨立的「備份此瀏覽器的待審資料與筆記」。

同一個選檔欄位可讀回 `FM24_PERSONAL_V1` 備份，或舊 `FM24_IMPORT_BATCH_V1` 批次檔。先預覽新增／相同／衝突數量；只新增沒有的 ID，衝突保留目前內容並列出識別碼。原備份檔仍保留另一份內容，可人工核對。

這份個人備份涵蓋 GitHub Pages 本機的待審批次、球員／俱樂部／賽事身分決定、優先核對筆記，不包含 claude.ai 平台共用文件庫；平台資料仍使用原本的各區匯出功能。正式統計只有在正式 Master 更新並重新匯入後才改變。貼上資料與匯入批次不會自行核准事實。

## 錯誤與環境

- Excel 在 Web Worker 中使用與本機相同的 Python 管線；首次執行下載固定版本 Pyodide、openpyxl 與 OpenCC。檔案在裝置內處理，下載引擎不需要上傳工作簿。
- 建置需要網路連到 jsDelivr / PyPI；完成的 HTML 閱讀與原始 Excel 取回不需要引擎。瀏覽器對本機 `file://` 的 IndexedDB / Worker 支援不同，推薦在公開 HTTPS 網站匯入；不能保存時仍可預覽與下載。
- 沒有 OpenCC、損壞 Excel、未快取公式、Excel 錯誤儲存格、缺少必要主表、校驗失敗皆停止；既有版本保留。公式必須先在 Excel 計算並儲存，不在網站猜算。
- 單一輸入上限 80 MB、XLSX 解壓上限 300 MB、工作表範圍總計上限 500 萬格。大面積空白格式可先在 Excel 清理。建置可取消，超過十分鐘停止並保留原版。
- 版本歷史使用 IndexedDB；空間不足或儲存被封鎖時不假裝套用成功。可以下載預覽成果作為另一份完整 HTML。
- SHA-256 用來核對內容與傳輸完整性，不是簽章，不能證明資料的真實性。

## 本機批次工具

安裝既有 `requirements.txt` 後，在 `fm24` 目錄執行：

```sh
python archive_exchange.py "新版World_Master.xlsx" -o "outputs/2035-36"
python archive_exchange.py "新版完整網站.html" -o "outputs/from-html"
```

輸入接受 `.xlsx`、附有 Excel 的完整 HTML、交換 JSON。一次輸出完整 HTML、原始 Excel、純網站資料 JSON、交換 JSON 與 `SHA256SUMS.json`。輸出目錄存在時拒絕覆寫；整份成功才移入目的目錄。加 `--site` 產出公開網站基準版。

開發者仍可單獨使用 `etl.py`、`build_site.py`。ETL 已改成同目錄暫存建置後原子替換，舊 `Ingest_*` 待審表會攜帶；舊資料庫損壞時拒絕繼續，避免靜默丟掉待審資料。`build_site.py --workbook` 會逐列確認 Excel 與 SQLite 同版，不能誤附另一版 Excel。
