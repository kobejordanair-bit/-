# 球員比較統計修正（2026-09-24）

使用者指出亞馬爾只有出場、進球，姆巴佩只剩出場。上一版把任一缺值擴大成整欄不顯示，且聯賽只讀生涯表，漏掉已在另一張表採用的季末分賽事資料。

## 修正

- 比較主要數值改為顯示已知範圍的小計，逐欄顯示「已填／在檔段數」。沒有任何已知值仍是未知；真實零保持零。
- 場均只使用同時有該指標與出場的紀錄，直接標示分母場次；不以局部進球除以全生涯出場。
- `Player_League_Career` 與 `Player_Club_Competition_Stats` 的明示 ADOPTED 聯賽觀測交叉核對。同 Player_ID、Season_ID、Club_ID 僅計一次；日期較新的觀測取代舊快照，不相加、不拿舊值補新快照缺欄。
- 日期取同來源同球員的快照日期，或來源名冊唯一日期；不從訊息 ID、列號或建置日期猜測。日期不明或同日矛盾，僅矛盾欄位停止加總，其餘欄位仍可呈現。
- 聯賽分類是明示清單；盃賽、國家隊、非正式比賽不入聯賽。534 個球季／俱樂部區段，涵蓋 40 個受控身分；原始與新舊觀測均可展開追溯。
- `Player_Career_Summaries` 的聯賽生涯總計按原日期獨立呈現，不把舊總計直接補進新累計。多段評分仍不做無依據的簡單平均。
- 巴薩逐季比較補上漏接的 `Clean_Sheets`、`Goals_Conceded`。

## 驗證

237 項 Python 與 46 項 Node 測試通過。回歸案例包含季末取代、重複去重、缺值小計、場均分母一致、來源矛盾僅阻擋該欄，以及門將逐季欄位保留。

原始 Excel、SQLite 均未修改；既有榮譽事實與球員身分不變。較早的 `PLAYER_COMPARISON.md` 記錄上一版交付，表現計算以本修正為準。
